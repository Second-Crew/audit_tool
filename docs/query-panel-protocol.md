# Fixed agency visibility panel

The 10 prompts in [`calibration-query-panel.json`](./calibration-query-panel.json) are frozen before outcome collection. They reflect San Jose and San Francisco ecommerce agency discovery, Shopify, WooCommerce, redesign, and migration intent. They do not contain the target brand. This panel measures only this market and these intents; it is not a universal GEO/AEO ranking.

For each AI answer engine, use the same signed-in/out state, model, search setting, language, and California location context for all observations. Isolate runs from prior chats and saved memories; a new conversation alone does not establish independence. Inspect the answer's source/provenance panel for memory or prior-chat references. Exclude a run if it uses either, or if isolation cannot be verified. ChatGPT Temporary chat defaults to **Personalized**, which can reference memory; choose **Unpersonalized** for isolation and preserve its transcript when a durable permalink is unavailable. Run each exact prompt independently three times, across at least two UTC dates for a prospect score. Rotate prompt order between repeats. Do not edit a prompt after seeing an answer. Record the timestamp, engine/model, prompt ID, run ID, whether an answer appeared, every cited URL, whether `secondcrew.com` was cited, whether Second Crew was mentioned without a citation, and a permalink or preserved transcript. Verify citations by opening their destinations; a brand mention alone is not a citation. Record failed, blocked, or memory-contaminated runs as invalid with a reason rather than silently treating them as misses.

Pass the 10 frozen query IDs to `scoreObservedVisibility` only after every prompt has three valid observations for one engine; the scorer withholds a result if those IDs are omitted. Report citation, answer-trigger, and brand-mention rates separately for each engine and date window. The score is descriptive of this fixed panel. Keep the raw observations available for review and compare later windows on the unchanged prompts. The two one-off ChatGPT Search observations in the methodology document preceded this frozen panel and do not count toward its 30 required runs. The initial 20 signed-in observations are retained as exploratory evidence but excluded because cross-chat memory was observed and isolation cannot be established for that collection batch. The [2026-09-26 reruns](./query-panel-reruns.json) contain 30 valid observations and one excluded run whose citation destination failed TLS verification. They were collected with account memory disabled, then restored, on one date; a later-date repeat is required for the two-engine prospect score.

When later-date ChatGPT observations are available, retain every valid attempt in the raw record. Build the 30-run scoring cohort using the earliest two valid 2026-09-26 runs for each query and the earliest valid later-date run for that query. This selection rule is fixed before later-date collection and does not depend on citation or mention outcomes. If a selected later-date attempt is invalid, keep it with its reason and use the next valid attempt for that query. Apply the same principle to Google AI Mode: the first two valid 2026-09-27 runs and the earliest valid later-date run per query. Do not relabel valid observations invalid merely to satisfy the scorer's exact 30-run input.

The query text was committed in `6c08521` on 2026-09-24 at 02:28:56 UTC, before these observations. The `frozenAt` field added later records that verifiable commit instant; it does not claim a more precise earlier drafting time. The [Google AI Mode partial panel](./query-panel-google-ai-mode-draft.json) contains two validated runs per prompt from 2026-09-27 UTC. Its 20 share links reopened to the exact prompts and answers. Every originally recorded URL was present on the saved answer page; a second review recorded newly visible links, including source cards that varied with the reopened view. Each distinct URL in the union was opened. Source carousels can vary, so the record preserves the URLs observed at both times and the review timestamp. Google source-viewer links are Google-owned place cards, not direct citations to the underlying business website. The panel remains unscored until a third valid run per prompt is collected on a later UTC date. Google Search personalization was temporarily off for collection and restored to on afterward.

For the SEO baseline, search each `seoQuery` on the same date and location/device context. Record organic web positions and landing URLs separately from ads, local packs, directory ranks, and AI overviews. Search Console query/page reports are the stronger first-party outcome source for the target domain; do not publish private exports in this repository. A crawl score may be compared with these observations, but it should not be trained or presented as a rank predictor from this small panel.

Google Search Console's [generative AI performance report](https://support.google.com/webmasters/answer/16984139?hl=en) separately reports link impressions in AI Overviews and AI Mode by page, country, device, and date. Keep that first-party Google series separate from the ChatGPT Search prompt panel and from ordinary organic positions. It does not supply the exact prompts, answer text, or cited URL sets required by this panel; do not substitute its impressions for panel citation runs.

Before using the panel to validate a predictive checklist, label a larger agency sample with comparable page types, include both visible and nonvisible agencies, and hold out sites and query dates from tuning. Track reviewer agreement and false positives. The current 10-query panel is a repeatable observation baseline, not enough by itself to validate weights or causality.
