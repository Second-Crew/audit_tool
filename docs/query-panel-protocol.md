# Fixed agency visibility panel

The 10 prompts in [`calibration-query-panel.json`](./calibration-query-panel.json) are frozen before outcome collection. They reflect San Jose and San Francisco ecommerce agency discovery, Shopify, WooCommerce, redesign, and migration intent. They do not contain the target brand. This panel measures only this market and these intents; it is not a universal GEO/AEO ranking.

For each AI answer engine, use the same signed-in/out state, model, search setting, language, and California location context for all observations. Isolate runs from prior chats and saved memories; a new conversation alone does not establish independence. Inspect the answer's source/provenance panel for memory or prior-chat references. Exclude a run if it uses either, or if isolation cannot be verified. ChatGPT Temporary chat defaults to **Personalized**, which can reference memory; choose **Unpersonalized** for isolation and preserve its transcript when a durable permalink is unavailable. Run each exact prompt independently three times, on at least two dates if possible. Rotate prompt order between repeats. Do not edit a prompt after seeing an answer. Record the timestamp, engine/model, prompt ID, run ID, whether an answer appeared, every cited URL, whether `secondcrew.com` was cited, whether Second Crew was mentioned without a citation, and a permalink or preserved transcript. Verify citations by opening their destinations; a brand mention alone is not a citation. Record failed, blocked, or memory-contaminated runs as invalid with a reason rather than silently treating them as misses.

Use `scoreObservedVisibility` with the 10 frozen query IDs only after every prompt has three valid observations for one engine. Report citation, answer-trigger, and brand-mention rates separately for each engine and date window. The score is descriptive of this fixed panel. Keep the raw observations available for review and compare later windows on the unchanged prompts. The two one-off ChatGPT Search observations in the methodology document preceded this frozen panel and do not count toward its 30 required runs. The initial 20 signed-in observations are retained as exploratory evidence but excluded because cross-chat memory was observed and isolation cannot be established for that collection batch.

For the SEO baseline, search each `seoQuery` on the same date and location/device context. Record organic web positions and landing URLs separately from ads, local packs, directory ranks, and AI overviews. Search Console query/page reports are the stronger first-party outcome source for the target domain; do not publish private exports in this repository. A crawl score may be compared with these observations, but it should not be trained or presented as a rank predictor from this small panel.

Google Search Console's [generative AI performance report](https://support.google.com/webmasters/answer/16984139?hl=en) separately reports link impressions in AI Overviews and AI Mode by page, country, device, and date. Keep that first-party Google series separate from the ChatGPT Search prompt panel and from ordinary organic positions. It does not supply the exact prompts, answer text, or cited URL sets required by this panel; do not substitute its impressions for panel citation runs.

Before using the panel to validate a predictive checklist, label a larger agency sample with comparable page types, include both visible and nonvisible agencies, and hold out sites and query dates from tuning. Track reviewer agreement and false positives. The current 10-query panel is a repeatable observation baseline, not enough by itself to validate weights or causality.
